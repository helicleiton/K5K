# K5K Virtual

Sintetizador aditivo gratuito para Windows (aplicativo e plugin VST3), inspirado no K5000S.

**Página e downloads:** https://helicleiton.github.io/K5K/

- Baixar o instalador: [K5K-Setup.exe](https://github.com/helicleiton/K5K/releases/latest/download/K5K-Setup.exe)
- Versão portátil: [K5K-win64.zip](https://github.com/helicleiton/K5K/releases/latest/download/K5K-win64.zip)

Programa gratuito e de código fechado. Problemas ou sugestões: abra uma *issue* neste repositório.

Kawai e K5000 são marcas da Kawai Musical Instruments Mfg. Co., Ltd. Este projeto não tem relação com a Kawai.
